# Creating the Trans Dimension Site Record

This guide walks a root admin through creating the Site record for The Trans Dimension at admin.placecal.org.

## Prerequisites

You need root access to the PlaceCal admin interface. Log in as a root user.

## Step-by-step instructions

### 1. Navigate to Sites

Go to admin.placecal.org and click Sites in the main navigation.

### 2. Create a new site

Click "New Site" to create a new record.

### 3. Basic Information tab

Fill in the following fields on the Basic Information tab.

Name: "The Trans Dimension"

Site Admin: Choose a user from the dropdown to be the site admin. They can later edit the site's content and images. Only root users can change this setting after creation.

Place Name: Leave blank (optional field for displaying alternative names on maps).

Contact Email: This email receives "get in touch" enquiries from the site's Join form. Leave as placeholder "<GI contact address>" for now. Contact Gendered Intelligence to supply the final email address.

Tagline: Leave blank or enter a short description of the site (optional).

Hero Text: Provide welcome text (maximum 120 characters). This appears prominently on the site's homepage.

Description: Leave blank or enter a longer description (optional).

### 4. Images and theme tab

Set Theme: Select "transdimension" from the theme dropdown.

Logo: Upload the Trans Dimension wordmark. The file is located at app/assets/images/transdimension/TDD_Logo_MobileHeader.svg (added by WP 2.2).

Footer Logo: Optional. Leave blank unless a footer-specific logo is needed.

Hero Image: Upload the homepage hero image. See the handbook link in the admin form for image specifications.

Hero Image Credit: Optional. Leave blank or enter the photographer or source.

Hero Image Alt Text: Provide descriptive alt text for the hero image for accessibility.

### 5. Neighbourhoods tab

Leave this tab empty. The Trans Dimension site carries no neighbourhoods. This means partners are scoped by tags alone rather than by geographic location. If neighbourhoods are added later, the neighbourhood dropdown will appear in the public site navigation.

### 6. Partnerships tab

Add partnership tags that define the site's coverage regions. Select both tags from the dropdown.

London (case-insensitive name match; check admin UI for exact id).

Manchester (case-insensitive name match; check admin UI for exact id).

These tags determine which partners appear on the site.

### 7. Settings tab

Publishing Status: Turn on "Published" to make the site live. The site will not appear publicly until this is enabled.

Slug: transdimension (autogenerated from the site name, but confirm it is correct).

URL: https://transdimension.uk (for production). For staging, use https://transdimension.<staging host> as a placeholder. This field cannot be edited after creation unless you are a root user.

### 8. Save

Click "Save Site" at the bottom of the form. The site is now created.

### 9. Verify with the check task

Run the check task to verify the Site record is configured correctly.

```bash
bin/rails transdimension:check
```

The task will print PASS or FAIL lines for each requirement. All checks should pass. If any checks fail, review the site record and correct the issues.

## Staging deployment

When deploying to staging, follow the same steps but use this URL instead.

URL: https://transdimension.<staging host>

Replace <staging host> with the actual staging hostname when deploying.

## Next steps

After the site is created and verified.

Run the page seed task to create the About and Privacy policy pages.

```bash
bin/rails transdimension:seed_pages[transdimension]
```

This task is documented in WP 2.6.
